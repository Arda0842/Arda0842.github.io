![Uploading image.png…]()

Kişisel yazılım projelerimi, oyun geliştirme serüvenimi ve sahip olduğum sertifikaları sergilediğim, tamamen modern web standartlarıyla geliştirilmiş dinamik ve interaktif portfolyo web sitem. 

## 🌟 Proje Hakkında

Bu proje, yeteneklerimi ve geliştirdiğim ürünleri potansiyel işverenlere, çalışma arkadaşlarına ve teknoloji meraklılarına sunmak için tasarlanmış tek sayfalık (Single-Page) bir web uygulamasıdır. Site, ziyaretçiye akıcı bir deneyim sunmak amacıyla CSS ve JavaScript animasyonlarıyla zenginleştirilmiş, kullanıcı dostu bir arayüze sahiptir.

## 🛠️ Kullanılan Teknolojiler

Bu portfolyo herhangi bir ağır framework kullanılmadan, saf (vanilla) web teknolojileriyle performansı maksimize edecek şekilde kodlanmıştır:

* **HTML5:** Semantik web yapısı.
* **CSS3:** Özelleştirilebilir değişkenler (CSS Variables), Grid/Flexbox mimarisi ve gelişmiş `@keyframes` animasyonları.
* **Vanilla JavaScript (ES6+):** DOM manipülasyonu, dinamik içerik oluşturma (sertifika filtreleme), localStorage yönetimi ve Canvas tabanlı parçacık fiziği.
* **HTML5 Canvas:** Arka planda fare hareketlerine duyarlı, temaya göre renk değiştiren interaktif ağ (network) animasyonu.
* **FontAwesome:** Ölçeklenebilir vektörel ikonlar.

## ✨ Öne Çıkan Özellikler

* **Gelişmiş Karanlık/Aydınlık Tema (Dark/Light Mode):** Kullanıcının tercihini tarayıcı önbelleğinde (`localStorage`) tutan, ekranı kaplayan özel bir "dalga (ripple)" ve "yerçekimi düşüşü" animasyonuyla tasarlanmış tema değiştirici.
* **İnteraktif Arka Plan:** Fare imlecinden kaçan ve kendi aralarında bağ kuran parçacıklardan oluşan Canvas motoru.
* **Dinamik Sertifika Sistemi:** JavaScript dizisi üzerinden beslenen; kuruma, teknolojiye veya kategoriye göre filtreleme yapabilen ve istatistikleri (toplam sertifika, kurum sayısı vb.) anlık hesaplayan sertifika sekmesi.
* **Daktilo Efekti:** Karşılama ekranında dikkat çeken, otomatik yazılan metin animasyonu.
* **Mini Proje Önizlemeleri:** Satranç, GridWar ve Yılan oyunu kartlarının üzerinde, CSS Grid ile kodlanmış küçük ve animasyonlu proje önizlemeleri.
* **Scroll-to-Top:** Belirli bir kaydırma mesafesinden sonra ortaya çıkan, sayfa başına yumuşak geçiş sağlayan akıllı buton.

## 🗂️ Sergilenen Projeler

Portfolyoda yer alan bazı temel projeler şunlardır:

1. **ARD FİNANS:** Yapay zeka destekli borsa analiz platformu.
2. **Dağ Yarışı:** Godot Engine kullanılarak geliştirilen fizik tabanlı 2D araç simülasyonu.
3. **Satranç:** Tarayıcı üzerinden oynanabilen, şah, mat, pat ve piyon terfisi gibi kuralları tam destekleyen web tabanlı satranç oyunu.
4. **Kayseri Boğası & Mayın Tarlası:** Masaüstü platformlar (WinForms vb.) için geliştirilmiş strateji oyunları.
5. **GridWar & Yılan:** Modernleştirilmiş, tarayıcı tabanlı klasik oyun deneyimleri.
